# Portfólio — Eduardo Sabino

Projeto simples criado com React, Vite, JSX e AOS.

## Executar

```bash
npm install
npm run dev
```

## Gerar a versão de produção

```bash
npm run build
```

A pasta `dist` gerada pode ser publicada na Vercel, Netlify ou outra hospedagem estática.

## Estrutura

- `src/App.jsx`: conteúdo e componentes do portfólio.
- `src/App.css`: visual, animações e responsividade.
- `src/index.css`: estilos globais da aplicação.
- `src/main.jsx`: inicialização do React.
- `public/favicon.svg`: ícone do site.
- `index.html`: metadados básicos.
